# Changelog

## [1.0.0] - 2024-01-15

### Added
- Initial release of BookSwap Flutter app
- Firebase Authentication with email/password
- Firestore database integration
- Book management (CRUD operations)
- Swap request system
- Real-time chat functionality
- Base64 image storage with compression
- Cross-platform support (iOS, Android, Web)
- Bottom navigation with 5 tabs
- User profile management
- Real-time updates across all features

### Features
- Browse available books from other users
- Post books with cover images
- Send and manage swap requests
- Accept/reject incoming offers
- Chat with users after swap acceptance
- User settings and profile management

### Technical
- Flutter 3.x framework
- Firebase Core, Auth, and Firestore
- Image picker and compression
- Material Design 3 theming
- Responsive design for all platforms
